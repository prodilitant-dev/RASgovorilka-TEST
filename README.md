# RASgovorilka — TEST

Экспериментальный репозиторий для аудита кода, рефакторинга и проверки идей
перед переносом в основной проект [RASgovorilka](https://github.com/prodilitant-dev/RASgovorilka).

## Скрипты

- `npm run lint` — проверка ESLint
- `npm run lint:fix` — автофиксы
- `npm run format` — Prettier
- `npm run format:check` — проверка форматирования
